Files in this directory are copied to the root of the published site, verbatim.

Put search engine verification files here — the `google<hash>.html` that Google Search
Console hands you, or Bing's `BingSiteAuth.xml`. They must sit at
`https://bisak.github.io/SpaceSwitchSpeed/<name>`, which is what this directory is for.

Names beginning with `_` or `.` are skipped, which is why this file is not published.
